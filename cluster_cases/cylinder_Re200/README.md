# cylinder_Re200 —— 二维圆柱绕流，Re = 200（瞬态 PIMPLE，涡街脱落）

自包含现场：网格 + control + 校验脚本。运行产物落在 `logs/`、`out/`。

**网格与 `cluster_cases/cylinder_Re40` 逐位相同**（md5 一致），几何/物性表沿用那边第 1 节，
所以两个现场可以直接对照「同一个分辨率下，稳态求解与瞬态求解的区别」。

## 1. 物理与网格

| 项 | 值 |
|---|---|
| 圆柱 | 半径 R = 0.5（D = 1），轴沿 z，展向 z ∈ [0,5] **一个单元厚** → 严格二维 |
| 远场 | 圆 r = 10（20 D） |
| 网格 | 非结构 2D：3928 单元 / 31424 四面体 / 80 个壁面环单元（平均 r = 0.5089，首层厚 0.0048） |
| 无量纲化 | ρ = 1，μ = 0.005，U_∞ = (1,0,0) → Re = ρU D/μ = **200** |
| 边界 | zone 6 = wall（圆柱无滑移）；zone 4 = symmetry（z 两平面）；zone 5 = **velocity-inlet (1,0,0)** |
| 参考 | Re = 200 是二维尾迹的周期极限环：St ≈ 0.196（Williamson & Brown 1998），平均 C_D ≈ 1.34 |

## 2. 这个现场演示什么：瞬态 PIMPLE 路径

Re = 200 远在二维尾迹稳定性极限（Re ≈ 47）之上，流场是**周期性 von Kármán 涡街**。
稳态求解器（SIMPLE）只能收到定常解或极限环的某个相位，**不能表示周期解**，
所以这个现场必须走瞬态路径：

```
transient = true
pimple    = true
time_scheme = 2      # BDF2，第 1 步退化为隐式 Euler
dt = 0.005           # CFL~ 0.07
n_time_max = 12000   # t_end = 60
n_outer_iter = 2     # 每个时间步 2 次 PIMPLE 外迭代
n_correct = 2        # 每次外迭代 2 次 PISO 压力修正
n_out_every = 100    # 每 100 步写一个快照（dt_snap = 0.5）
alpha_u = 0.7   alpha_p = 1.0
conv_blend = 1.0   nonorth_corr = 0.0   ppe_precond = ic0
lin_tol = 1e-8   lin_max = 300
```

**PIMPLE 只在 MPI 驱动里有实现**（`mod_uns_driver_mpi → pimple_run_mpi`）；串行二进制会
**静默忽略** `transient = true`，把算例当成一个稳态算例跑完。`mix.control` 里
`uns_parallel = always` 让 METIS 分块路径在 np = 1 时也生效，所以 `run.sh` **永远**调
`bin/mixnsolver_mpi`（先 `make mpi -j1` 构建）。

## 3. 远场必须用 `velocity-inlet`（本现场最容易踩的坑）

| 远场 BC | 稳态（cylinder_Re40） | 瞬态（本现场） |
|---|---|---|
| `pressure-far-field` | ✅ 能用 | ❌ **每步放大 ~2 倍**（独立于 dt） |
| `velocity-inlet 1 0 0` | ✅ | ✅ 稳定，CFL~0.07 |

`pressure-far-field` 同时给远场面**Dirichlet 速度 + Dirichlet 压力**。稳态 SIMPLE 容忍这个
过约束；瞬态 PIMPLE 不接受：冷启动实测 max\|u\| 按 1.6 → 4.3 → 8.7 → 14 增长，
`dt = 5e-3` 和 `dt = 1e-2` 行为一致（所以不是步长问题，是边界条件过约束），约 50 步就溢出。

`velocity-inlet` 只钉住速度：压力规范由 PPE（钉住 cell 1）决定，不会过约束。
在**闭合圆**上均匀来流的净质量通量恒为 0（∮U·n = U·∮n = 0），所以 r = 10 是合法的外边界。

> 代价：`velocity-inlet` 作用于**整个** zone 5，所以它的下游半边也是固定值的，
> 尾迹在 r = 10 处被强行拉回自由来流。脱落**仍然能够起振并饱和**（见第 4 节），
> 但这是本现场最主要的物理近似。

## 4. 实测（本 bundle，HEAD 二进制，np = 2，12000 步 / t = 60）

### 4.1 脱落的确立过程

把 12000 步等分成 12 段，看日志里两个量的段平均：

| 时间段 t | max\|u\| 段平均（段内 min–max） | du/dt 段平均 | 解读 |
|---|---|---|---|
| 0–5 | 1.5480（1.40–2.19） | 2.250 | 启动瞬态（脉冲启动、势流过冲） |
| **5–10** | **1.40000（min = max = 1.40000）** | 0.154 | **对称定常基流**（尾迹闭合、无横向运动） |
| 10–15 | 1.41072（1.40–1.42） | 0.200 | 反对称模态开始指数增长 |
| 15–20 | 1.41623（1.41–1.43） | 0.380 | 增长 |
| 20–25 | 1.44567（1.42–1.46） | 0.685 | 增长 |
| 25–30 | 1.45179（1.41–1.51） | 0.907 | 增长 |
| 30–35 | 1.44273（1.40–1.51） | 0.929 | 接近饱和（振幅已达终值） |
| 35–40 | 1.45183（1.40–1.49） | 0.970 | 饱和 |
| 40–45 | 1.45961（1.41–1.49） | 1.004 | **极限环** |
| 45–50 | 1.44894（1.40–1.49） | 1.013 | 极限环 |
| 50–55 | 1.43940（1.40–1.48） | 1.006 | 极限环 |
| 55–60 | 1.44725（1.40–1.49） | 1.012 | 极限环 |

* **起振点 t ≈ 10**：t = 5–10 段 `max|u|` 的 min 和 max **都是 1.40000**，也就是整段恒定
  （连续 1000 步逐位不变）——这正是 Re > 47 时「不稳定但对称」的基流；t > 10 后这个常数被
  打破（段 min 开始出现 1.41/1.42），反对称模态开始增长。
* 饱和后 `max|u|` 的**下限始终回到 1.40000**，振荡表现为「从基流的 1.40 冲到 1.49」，
  即脱落是在对称基流上叠加的调制。
* **饱和 t ≈ 40**：`du/dt` 在 t = 40 后进入 ~1.0 的平台（每步 Δu ~ 5e-3，约 0.5% 的 max|u|），
  四个 5 秒段的段平均不再漂移。**所以 t_end = 60 已经覆盖「起振 + 饱和 + 20 个周期」。**
* `du/dt`（日志里 = max|Δu|/dt）**不是**干净的脱落信号：它是网格尺度噪声主导的量，
  饱和后停在 ~1.0（Δu ~ 5e-3 每步），只能用来判断「没有在增长」，不能用来测频率。

### 4.2 Strouhal 数与振幅（来自全精度 VTU 快照，不是日志）

日志里的速度是 3 位有效数字输出（`1.44E+00`），**用它做 FFT 只能得到 St ≈ 0.144，
是量化假象**。必须用快照（每个分量 12 位有效数字）：

```
python3 check_cylinder_unsteady.py 0.005 out/cylinder_Re200_np2.step*.vtu
```

| 探针 | 均值 | 去趋势 rms | 峰峰值 | 主频 | St = f D/U | 主频振幅 |
|---|---|---|---|---|---|---|
| u_y(x=3, y=+0.6) | −0.0795 | **0.309** | **0.927** | 0.1561 | **0.156** | 0.399 |
| max\|u\|（全场） | 1.4480 | 0.0245 | 0.0766 | 0.1571 | **0.157** | 0.0305 |
| u_y(+0.6) − u_y(−0.6) | −0.2119 | 0.181 | 0.529 | 0.3043 | 0.304 | 0.230 |

* 两个互相独立的量（尾迹里单点 u_y、全场 max\|u\|）给出同一个频率
  **f = 0.156–0.157 → St = 0.156 ± 0.01**，且在 t = 35–60 的窗口（`df = 0.042`，
  峰顶做了抛物线插值到子格）上是稳定的。
* 与文献 St = 0.196（Re = 200）相比**偏低约 20%**。这张网格只有 80 个周向单元、
  尾迹里没有任何加密（x = 3 处单元尺度 ~0.4 D），是频率亏损最可能的原因；
  远场 r = 10 的固定值也把尾迹压短。**要把 St 当定量结果用，先把尾迹加密**。
* 振幅：尾迹单点横向速度峰峰值 0.93 U_∞、rms 0.31 U_∞；全场 max\|u_y\| = 0.71 U_∞。
  这是一个**强**非定常尾迹，不是数值抖动（`mass-imbal ~ 1e-18`、`lin-res ~ 1e-9`
  全程正常，见 4.5）。
* 第三行的差信号主频是**基频的 2 倍**（0.304 ≈ 2 × 0.156）：在 x = 3 这个近场位置，
  u_y 在 y = ±0.6 两点主要是**同相**的（未定常升力主导的横向运动），反对称成分是次阶；
  想把脱落看得更「教科书」，探针要放到 x ≳ 5 D。

### 4.4 末态受力与分离（求解器在收尾时打印的最后一次后处理，t = 60 瞬时）

`PIMPLE (MPI) finished: 12000 time steps` 之后，rank 0 会对汇总后的全局场做一次
后处理（`mod_uns_driver_mpi.f90` 第 350 行起），所以日志**尾部**才有这些量
（时间推进过程中**没有**力历史）：

| 量 | 实测（t = 60 瞬时） | 参考 |
|---|---|---|
| max\|u\| / max p / min p | 1.4402 / +0.5203 / −1.1068 | — |
| Pressure F_x / Viscous F_x | 2.5996 / 0.6069 | — |
| **Total F_x（阻力）** | **3.2064** → **C_D = 1.285** | 文献平均 C_D ≈ 1.34 |
| Total F_y（升力） | −0.7623 → C_L = −0.305 | 瞬时值，随脱落相位振荡 |
| 分离点（自前驻点） | 上 107.4° / 下 120.2° | Re = 200 长期平均 ~110–116° |
| 回流长度 | 1.798 D | ~1.5–2 D |

* C_D 用求解器自己报的 `Reference area = 4.9923`（= D × 展向有效厚度，`D = 1`，
  展向名义 5；这个 4.9923 是求解器按形心范围算出来的，比 5 小 0.15%，
  自己按 A = 5 复算 C_D 会差同样的 0.15%）。
* 与文献平均 C_D ≈ 1.34 差 4% 以内——**比 St 的表现好得多**，说明这张网格把纵向力
  积分得不错，频率/相位类量才是它对分辨率最敏感的部分。
* 分离角与回流长度是**瞬时**值：Re = 200 时它们在脱落周期内左右摆动
  （对照 `cluster_cases/cylinder_Re40` 里稳定对称的 51.7°/51.6°）。
* 日志尾部还会打印 `Ghia reference: no table for this Re, skipped.`——那是**空腔算例专用**
  的后处理（竖中心线 u_x 对 Ghia 表），在圆柱算例里只会跳过，属正常。

## 5. 运行

```bash

./run.sh 4        # 4 rank
python3 check_cylinder_unsteady.py 0.005 out/cylinder_Re200_np4.step*.vtu
```

`run.sh` 把最终场 `unMesh.vtu` 和全部快照 `unMesh.vtu_step*.vtu` 搬进 `out/`，
并改名为 `<tag>.step<NNNN>.vtu`；求解器日志（含每步 CFL/lin-res/du/dt）在 `logs/`。

## 6. `check_cylinder_unsteady.py` 说明

```
usage: check_cylinder_unsteady.py <dt> <snapshot.vtu ...>
```

* 读 ASCII VTU，点 = 网格节点 + **每个单元一个形心点**；tets 形如
  `n_pts i1 i2 i3 centroid_id`，用「唯一的形心 id」恢复每个求解单元的单一值。
* 按文件名里的 step 号推出时间 `t = step*dt`（不需要在 VTU 里存时间）。
* 三个信号：`u_y(x=3, y=+0.6)`、全场 `max|u|`、`u_y(+0.6) − u_y(−0.6)`；
  探针用与 `mod_uns_output.f90` 一致的 8 近邻反比距离插值。
* 每个信号：去趋势 → Hann 窗 → 取**后 40% 的时间窗**做 FFT → 峰值位置再做
  **抛物线插值**（子格精度）；打印 St、峰峰/rms 振幅，并给出「振荡 / 单调」判据。
* 注意频率分辨率由**时间窗长度**决定（本算例 `df = 1/23 = 0.042`），
  加密快照（改小 `n_out_every`）**不会**提高频率分辨率，只会减小峰值偏置。

## 7. 备注

* **收敛判据**：瞬态算例不存在 `CONVERGED` 行，跑到 `n_time_max` 正常收尾；
  判据看 `du/dt` 是否进入平台（第 4.1 节）+ `check_cylinder_unsteady.py` 的 St/振幅。
* **重启（2026-10-13：修复并验证）**：`restart = true` + `restart_file = <dump>` +
  `dump_file = <dump>` 可从中断处续算；把长算例切成 ≤10 min 的**链式**多段是推荐用法。
  dump 现在带**时间历史 ＋ 阶数**（`ts_order`），从 `ts_order=2` 的 dump 续算**第一步就
  保持二阶**；此前 dump 的历史全零、`ts_order` 丢失，且重启第一步被无条件强制一阶，
  200 步内就把 BDF2 轨迹拖成一阶（实测 3 步差 1.6%）。重启边界那一步仍有 ~1% 的差别
  （来自未转储的内部面通量），但**不累积**，实测见第 8 节。
* 日志里没有 C_L/C_D 力历史（`max|u|` 是最接近的代理量）；St 只能从快照得到。
* 磁盘：12000 步 / `n_out_every = 200` → **60 个快照**，每个约 **4.1 MB**（ASCII VTU，
  3928 单元 / 25760 节点），加末态场共 **约 250 MB**。频率分辨率由**时间窗长度**决定
  （第 6 节），调小 `n_out_every` 只减小峰值偏置，却成倍吃磁盘——先算配额。
* 核数声明与守卫（`n_struct_ranks` + `n_uns_ranks`，退出码 6/7/8）见
  `cluster_cases/README.md` 第 3 节；本现场目录里的 `mix.control` 已经把
  `uns_parallel = always` 打开。
* 稳态对照：`cluster_cases/cylinder_Re40` 用的是**同一张网格**、但走稳态 SIMPLE 路径
  （Re = 40，尾迹定常）。把两个现场的日志并排看，就是「稳态求解器 vs 瞬态求解器」在同一
  分辨率下的行为差别。`cases/cylinder_cas/cylinder.cas` 也是这张网格（无 control 文件）。

## 8. 分段续算（链式重启）验证（2026-10-13）

为把 12000 步（t = 0→60）的算例装进「单次 ≤10 min」的资源约束，本现场把它切成两段：
**段 1** 冷启动 6000 步（t = 0→30）写下 `cyl200_dump_t30.txt`；**段 2**
`restart = true` + `restart_file = cyl200_dump_t30.txt` 再跑 6000 步（t = 30→60）写下
`cyl200_dump_t60.txt`。每段 **约 4.5 min**（np2 / 3928 单元 / 每步 198 次线性迭代）。

| 量（t = 60 瞬时） | 连续 12000 步（第 4.2、4.4 节参考值） | 链式 6000 + 6000（t = 30 处重启） |
|---|---|---|
| `max\|u\|` | 1.4402 | **1.44014** |
| Total F_x → 平均 `C_D` | 3.2064 → 1.285 | **3.206372 → 1.285** |
| Total F_y → `C_L` | −0.7623 → −0.305 | **−0.761569 → −0.305** |
| 分离点（自前驻点） | 107.4° / 120.2° | **107.37° / 120.16°** |
| 回流长度 | 1.798 D | **1.798 D** |
| `St`（t ≈ 36–60 快照窗，`u_y(x=3,y=+0.6)`） | 0.1561 | **0.1561** |

* 即**重启不改变脱落频率与时间平均受力**（对到 4–5 位有效数字）。物理上这是必然的：
  非定常尾迹是**稳定极限环**，重启边界引入的 ~1% 一步扰动会被重收敛与环的吸引性很快
  抹掉。专门的链式回归给出定量衰减（`.dbg/retest/restart_test/run_chained.sh`：
  400 步连续 vs 2×200 步链式，末态 `max|u|` 差 6e−5、全场差 ~1e−3）。
* **本次段 2 用的 `t30` dump 是修复前写出的**（`ts_order = 0`、历史块全零）：重启时
  第一步退回一阶 Euler 自举、第二步起自动回到 BDF2（历史在解新步之前从恢复态平移
  一级，故文件里的零历史只被第一步用到），结果与连续参考一致 —— 旧 dump 仍可用。
  修复后写出的 dump（`ts_order = 2` ＋真实两级历史）**第一步就保持二阶**
  （`cyl200_dump_t60.txt` 头注释即 `# ts_order: 2`）。
* 复现（现场目录 `.dbg/retest/cyl200/`；`mix.control` 已打开 `uns_parallel = always`）：
  ```bash
  # 段 1：t = 0 → 30（restart = false, dump_file = cyl200_dump_t30.txt）
  GFORTRAN_UNBUFFERED_ALL=y timeout 600 mpirun -np 2 ../../../bin/mixnsolver_mpi > ../logs/chunk1.log 2>&1
  # 段 2：t = 30 → 60（restart = true, restart_file = cyl200_dump_t30.txt,
  #                   dump_file = cyl200_dump_t60.txt, n_time_max = 6000）
  GFORTRAN_UNBUFFERED_ALL=y timeout 600 mpirun -np 2 ../../../bin/mixnsolver_mpi > ../logs/chunk2.log 2>&1
  python3 ../../../cluster_cases/cylinder_Re200/check_cylinder_unsteady.py \
          0.005 snapshots/cyl200_step*.vtu
  ```
  快照按**全局**步号命名（`snapshots/cyl200_step12000.vtu` = t = 60）：段 2 写出的
  `unMesh.vtu_step<NNNN>.vtu` 已按 `6000 + NNNN` 改名，两段拼成 t = 1→60 的单条序列
  （共 60 个 4.1 MB 快照）。
