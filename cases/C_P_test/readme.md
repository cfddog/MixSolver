Besides geometry size, the dimensionless parameters controlling the transpiration cooling performance can be
achieved with the governing equations nondimensionalized, which are: Reynolds number $\mathrm{Re} = \rho U_{in} L/\mu$;
Prandtl number $\mathrm{Pr}$; coolant flow injection rate $F = V_c/U_{in}$; porosity $\varepsilon$; Darcy number
$\mathrm{Da} = K/L^2$; and the thermal conductivity ratio $\lambda_s/\lambda_f$. In the following simulations, the above
dimensionless parameters are considered to be defaults without special emphasis, which are: $Ma=0.3$,$Tinf=300K$, $\mathrm{Re} = 5\mathrm{e}4$,
$\mathrm{Pr} = 0.7$, $F = 0.1\%$, $\varepsilon = 0.5$, $\mathrm{Da} = 5\mathrm{e}\text{-}7$, $\lambda_s/\lambda_f = 10$,
and $C_F = 0.0$. In this article, the influences of some parameters including $\mathrm{Re}$, $F$, $\lambda_s/\lambda_f$,
and the pressure gradient of the mainstream on the transpiration cooling performance and transpiration boundary layer
characteristics are studied.
