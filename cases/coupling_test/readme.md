# 流体–固体–多孔三相求解器验证方案

**条件：固体静止，考虑传热；先验证两两界面，再验证三相点。**

---

## 0. 约定与基本假设

### 0.1 符号约定

| 符号 | 含义 |
|---|---|
| \(\mathbf n\) | 流体侧外法向，从流体指向另一相 |
| \(\mathbf v_f\) | 流体速度 |
| \(\mathbf v_s\) | 固体速度，固体静止时 \(\mathbf v_s=\mathbf 0\) |
| \(\mathbf v_D\) | 多孔介质达西速度 |
| \(\mathbf v_p\) | 多孔介质孔隙速度，\(\mathbf v_D=\phi\mathbf v_p\) |
| \(T_f,T_s,T_p\) | 流体、固体、多孔温度 |
| \(k_f,k_s,k_{\text{eff}}\) | 流体、固体、多孔有效导热系数 |
| \(h_c\) | 接触热阻系数 |
| \(q_n\) | 法向热流，\(q_n=-k\frac{\partial T}{\partial n}\) |

### 0.2 固体静止的处理

固体区域只需解能量方程，速度为零：

\[
\mathbf v_s=\mathbf 0
\]

流体–固体界面不再需要运动学耦合，只保留传热耦合。

---

## 1. 界面条件总表

| 界面 | 流动/速度条件 | 温度条件 | 热流条件 |
|---|---|---|---|
| 流体–固体 | 无滑移：\(\mathbf v_f=\mathbf 0\)；滑移：\(\mathbf v_f\cdot\mathbf n=0\) | \(T_f=T_s\) | \(k_f\frac{\partial T_f}{\partial n}=k_s\frac{\partial T_s}{\partial n}\) |
| 流体–多孔 | 法向质量通量连续：\(\rho_f\mathbf v_f\cdot\mathbf n=\rho_f\mathbf v_D\cdot\mathbf n\)；切向用 Beavers–Joseph/Saffman | 局部热平衡 LTE：\(T_f=T_p\) | \(k_f\frac{\partial T_f}{\partial n}=k_{\text{eff}}\frac{\partial T_p}{\partial n}\) |
| 固体–多孔 | 不透水：\(\mathbf v_D\cdot\mathbf n=0\)；或位移连续 | \(T_s=T_p\) | \(k_s\frac{\partial T_s}{\partial n}=k_{\text{eff}}\frac{\partial T_p}{\partial n}\) |

有接触热阻时，流体–固体界面改为：

\[
k_f\frac{\partial T_f}{\partial n}=h_c(T_f-T_s)=-k_s\frac{\partial T_s}{\partial n}
\]

局部非热平衡 LTNE 时，多孔内需分别解流体温度和固体骨架温度，界面条件需增加相应热交换项。

---

## 2. 两两界面验证方案

### 2.1 流体–固体界面

#### 测试 A：一维稳态纯导热串联

**几何**  
左流体，右固体，界面在 \(x=0\)，长度分别为 \(L_f,L_s\)。

**边界**  
左端 \(T=T_L\)，右端 \(T=T_R\)；速度全部为零。

**解析解**  
温度线性分布，界面处温度连续、热流连续。

**检查量**

- 界面温度跳跃：\(|T_f(0)-T_s(0)|\)
- 界面热流跳跃：\(|k_f\partial T_f/\partial n-k_s\partial T_s/\partial n|\)
- 误差随网格细化收敛

**提示词**

- “在界面两侧插值到同一坐标，计算温度差和热流差。”
- “用 \(L^2\) 范数计算界面误差，检查收敛阶。”
- “将 \(k_s\to\infty\)，检查界面温度是否趋于流体侧温度。”

#### 测试 B：Poiseuille 流 + 固体导热

**几何**  
下方固体，上方流体通道，压力驱动。

**边界**  
底部固体给定温度或热流，顶部绝热或等温。

**检查量**

- 界面流体速度为零
- 界面温度连续
- 界面热流连续
- 流体温度剖面与固体内部线性温度匹配

**提示词**

- “检查界面处流体速度是否为零。”
- “积分界面热流，验证与固体内部热流一致。”

---

### 2.2 流体–多孔界面

#### 测试 A：一维稳态纯导热串联

**几何**  
左流体，右多孔，界面在 \(x=0\)。多孔内流体静止。

**边界**  
两端给定温度。

**解析解**  
线性温度，界面热流连续：

\[
k_f\frac{\partial T_f}{\partial n}=k_{\text{eff}}\frac{\partial T_p}{\partial n}
\]

**检查量**

- 温度连续
- 热流连续
- \(k_{\text{eff}}\) 是否按模型正确计算

**提示词**

- “多孔内速度设为零，排除对流影响。”
- “检查 \(k_{\text{eff}}\) 是否按 \(\phi k_f+(1-\phi)k_s\) 或所选模型计算。”

#### 测试 B：Beavers–Joseph 通道流 + 传热

**几何**  
上方自由流体，下方多孔床，压力驱动。

**解析基准**  
Beavers–Joseph 半解析速度剖面；温度可分层解析。

**检查量**

- 界面法向通量连续
- 滑移速度满足

\[
\frac{\partial u_f}{\partial n}=\frac{\alpha}{\sqrt{K}}\left(u_f-\frac{u_D}{\phi}\right)
\]

或 Saffman 近似。

- 温度连续
- 热流连续

**提示词**

- “对比半解析滑移速度，检查 \(\alpha\) 和 \(K\) 的影响。”
- “检查界面热流是否等于多孔有效热流。”

---

### 2.3 固体–多孔界面

#### 测试 A：一维稳态纯导热串联

**几何**  
左固体，右多孔，界面在 \(x=0\)。多孔内流体静止。

**边界**  
两端给定温度。

**检查量**

- \(T_s=T_p\)
- \(k_s\partial T_s/\partial n=k_{\text{eff}}\partial T_p/\partial n\)
- 若固体不透水，\(\mathbf v_D\cdot\mathbf n=0\)

**提示词**

- “若固体不透水，检查 \(\mathbf v_D\cdot\mathbf n=0\)。”
- “将多孔有效导热系数趋于固体导热系数，检查温度场是否连续过渡。”

#### 测试 B：Terzaghi 固结 + 传热

**几何**  
多孔层在刚性不透水基底上，顶部排水。

**解析基准**  
Terzaghi 一维固结孔压和沉降解。

**检查量**

- 位移连续
- 总应力连续
- 孔压扩散正确
- 热流连续

**提示词**

- “先关闭温度，验证固结；再开启温度，验证热–孔弹性耦合。”
- “检查不透水边界 \(\mathbf v_D\cdot\mathbf n=0\)。”

## 3. 三相点验证方案

### 3.1 纯导热三相点测试（首选）

**几何**  
二维正方形 \([0,1]\times[0,1]\)，中心点 \((0.5,0.5)\) 为三相点。  
左上扇形：流体；右上扇形：固体；下半扇形：多孔。

**边界**  
外边界给定不同温度或热流；所有速度为零。

**控制方程**  
稳态热传导。

**检查量**

1. 三相点处温度连续：

\[
T_f=T_s=T_p
\]

2. 小圆积分热流平衡：

\[
R_q(r)=\sum_i \int_{\Gamma_i(r)} k_i\nabla T_i\cdot\mathbf n_i\,dl
\]

随 \(r\to0\) 和网格细化，\(R_q\to0\)。

3. 整体能量守恒：总热流进 = 总热流出。

**提示词**

- “在三相点周围取半径 \(r\) 的小圆，分别积分各相热流。”
- “逐步减小 \(r\) 和网格尺寸，检查 \(R_q\) 的收敛阶。”
- “用 MMS 制造解析温度场，强制界面条件，验证代码。”

### 3.2 带流动的三相点测试

**几何**  
同上，但流体和多孔内有流动，固体静止。

**边界**  
流体入口给定速度/压力，多孔出口给定压力；温度边界。

**检查量**

1. 质量守恒：

\[
R_m=\sum_i \int_{\Gamma_i} \rho\mathbf v_i\cdot\mathbf n_i\,dl\to0
\]

2. 热流平衡：

\[
R_q=\sum_i \int_{\Gamma_i} k_i\nabla T_i\cdot\mathbf n_i\,dl\to0
\]

3. 动量平衡（若考虑表面张力）：

\[
\mathbf R_f=\sum_i \int_{\Gamma_i} \boldsymbol\sigma_i\cdot\mathbf n_i\,dl\to0
\]

**提示词**

- “先验证纯导热，再开启流动，逐步增加耦合。”
- “检查三相点附近网格是否足够加密，避免奇异性主导误差。”
- “使用小控制体积分，而不是仅看点值。”

## 4. 通用验证提示词

1. **界面插值检查**  
   “在界面两侧取相同物理坐标，插值温度和热流，计算跳跃量。”

2. **热流守恒检查**  
   “计算界面法向热流 \(q_n=-k\partial T/\partial n\)，检查两侧是否相等。”

3. **收敛性检查**  
   “网格加密 \(h, h/2, h/4\)，计算误差 \(L^2\) 范数，求收敛阶。”

4. **极限退化检查**  
   “\(K\to\infty\)：多孔退化为流体；\(K\to0\)：多孔退化为固体；\(k_s\to\infty\)：固体等温。”

5. **整体守恒检查**  
   “对整个域积分能量方程，检查总热流平衡。”

6. **MMS 制造解**  
   “选取解析 \(T_f,T_s,T_p\)，代入方程求源项，强制界面条件，验证离散解收敛。”

7. **三相点小控制体**  
   “以三相点为中心取小圆，积分各相热流、质量通量，检查残差随 \(r\) 和网格减小。”

8. **符号一致性**  
   “确认所有法向均从流体指向外部，避免热流符号错误。”

## 7. 推荐验证顺序

1. 单相纯导热  
2. 流体–固体纯导热  
3. 流体–多孔纯导热  
4. 固体–多孔纯导热  
5. 两两界面带流动  
6. 三相点纯导热  
7. 三相点带流动  
8. 整体守恒与网格收敛  
9. MMS 严格验证  
10. 极限退化与文献基准对比

---

**总结**  
固体静止时，速度条件简化，但传热耦合仍是双向的。验证核心是：先两两界面检查温度连续与热流连续，再在三相点用小控制体积分检查热流、质量和动量平衡。最有力的工具是解析基准、MMS、极限退化和整体守恒检查。
